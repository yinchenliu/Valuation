## Decisions, each with its reason

| Decision | Reason / citation | Why this and not the alternative |
|---|---|---|
| One helper builds every fixture PDF from the fixture's JSON | Assignment step 1: "one helper that builds the pages from the fixture's own printed lines, so each fixture and its PDF cannot drift apart" | A PDF written by hand per fixture would drift the first time a figure changed |
| Route A's scripted-answer PDF prints the **union** of all scripted answers | Step 1: a real PDF "that prints every row its Pass 1 JSON cites". `[DROPPED, GOOD]` cites rows of both answers | Printing only the first answer would add page failures to the arithmetic-retry tests and change what they test |
| `reprint_filing_pdf` after a test edits a row | Step 1: "write the PDF before the session file". The hash must be of the bytes on disk | Leaving the old PDF would put a page failure into `test_explicit_zero_is_accepted` (`validation_errors == []`) and would make `test_check_exit_codes`'s exit 1 partly a page failure |
| `leading` keyword on `write_text_pdf`, default 20 | 39 rows on page 50 (2022 filing) do not fit at 20 points | A second PDF writer would duplicate `_text_pdf.py` |
| The helper skips a malformed row instead of printing it | Stop tests break a row after the PDF is written, and a malformed row has nothing to print | No repaired test depends on this: each stop happens at shape, before the page check |
| "a figure that only matches with a sign": **no not-found case written for the sign** | Rule step 2: "Signs and parentheses are not compared". Under the rule as written, a figure differing only in sign **is** found. So I locked `-26642` against `(26,642)` as found, and the not-found cases are magnitude only (`2,664.2`, `266,420`, `26.642`, `26,643`) | Asserting "not found" for a sign would contradict the documented rule. See finding 2 |
| No test for backlog item 64 or item 63 | Assignment "Known open items" | Each wrapped-label case has figures on one half only, so item 64's candidate fix ("a neighbour that prints no figure may join") leaves them unchanged. The no-text-layer case is tested through the walk and route B only, never route A's retry count |
