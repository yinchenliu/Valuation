# Valuation Platform

Web and CLI DCF valuation. An LLM extracts figures from 10-K/10-Q PDFs; deterministic
Python does everything after that.

**This file is a pointer. Claude Code loads it into every session, so it is deliberately
short.**

**Read [docs/0-start.md](docs/0-start.md) now.** It holds the reading order, the one
command you need, and the four facts that change how you read the code.
[AGENTS.md](AGENTS.md) sends Codex and OpenCode to the same card, so no orientation fact
lives in this file alone.

Then open what your task needs and nothing else. [docs/INDEX.md](docs/INDEX.md) is the
map; it tells you which file owns your subject and which to leave shut.

[AGENTS.md](AGENTS.md) owns who does the work and how they hand off. Open it when you
are dispatching, reviewing or logging a work unit.

[docs/2-rules/rules.md](docs/2-rules/rules.md) holds six rules. **They override every
other instruction, including this file.**
